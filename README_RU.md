## 1. PayTrade Marketplace

PayTrade Marketplace — маркетплейс цифровых товаров и услуг с гарантом со стороны PayTrade.

Площадка предназначена для покупки и продажи цифровых товаров. Сделки проходят через PayTrade, который обеспечивает последовательность передачи товара и подтверждения оплаты.

1. Покупатель выбирает интересующий товар в каталоге.
2. Покупатель оформляет заказ и производит оплату.
3. После подтверждения оплаты создаётся заказ.
4. Продавец передаёт товар покупателю.
5. Покупатель проверяет полученный товар и подтверждает получение.
6. После подтверждения средства зачисляются продавцу на баланс PayTrade.

Таким образом, продавец получает средства после подтверждения получения товара покупателем.

Основные возможности маркетплейса:

- Каталог цифровых товаров.
- Поиск товаров по названию.
- Категории товаров.
- Карточки товаров с описанием и ценой.
- Профили продавцов.
- Система оценок и отзывов.
- Корзина и оформление заказов.
- Избранные товары.
- Управление собственными объявлениями.
- Изменение информации о товарах.
- Скидки и продвижение объявлений.
- Оплата через баланс PayTrade и Telegram Stars.
- История покупок.
- Обращения в службу поддержки.

## 2. PayTrade API

PayTrade API — самостоятельный платёжный интерфейс, предназначенный для разработчиков, которые хотят подключить PayTrade к собственным проектам.

С его помощью можно создавать платежи, получать информацию о них, отменять платежи и отслеживать изменение их статусов.

API подходит для интеграции в:

- Telegram-ботов.
- Интернет-магазины.
- Маркетплейсы.
- Веб-приложения.
- Сторонние сервисы.
- Другие проекты, которым необходима система приёма платежей.

PayTrade API не управляет товарами, объявлениями или сделками маркетплейса. Он отвечает за платёжную часть сторонних проектов.

Основные возможности API:

- Получение информации об аккаунте.
- Создание платёжных счетов.
- Получение информации о платежах.
- Отмена платежей.
- Отслеживание статусов платежей.
- Ожидание изменения статуса платежа.
- Тестовый режим.
- Приём платежей в Telegram Stars.
- Зачисление полученных через API средств на баланс PayTrade.
- Вывод полученных через API Telegram Stars на баланс PayTrade.

## 3. Общий баланс PayTrade

PayTrade Marketplace и PayTrade API являются двумя самостоятельными продуктами.

Их объединяет общий баланс PayTrade.

Средства, доступные на балансе, могут использоваться в рамках предусмотренных возможностей экосистемы.

## 4. PayTrade SDK

PayTrade SDK — Python-библиотека для удобной работы с PayTrade API.

SDK предоставляет готовые методы для взаимодействия с API, поэтому разработчику не нужно самостоятельно реализовывать каждый HTTP-запрос.

### Требования

- Python 3.10 или новее.
- Установленный PayTrade SDK.
- API-ключ PayTrade.

### Установка

SDK распространяется в формате `.whl`.

После получения файла библиотеки установите её командой:

```bash
pip install paytrade_sdk-0.2.0-py3-none-any.whl
```

После установки библиотека доступна для импорта:

```python
from paytrade_sdk import PayTrade, PayTradeError
```

Для работы с API необходимо создать экземпляр `PayTrade`, передав ему API-ключ и адрес API.

Базовый адрес API:

```text
https://a-ktj8.onrender.com
```

API-ключ используется для авторизации запросов.

## 5. Методы SDK

SDK предоставляет следующие основные методы:

| Метод                        | Описание                                      |
| ---------------------------- | --------------------------------------------- |
| `me()`                       | Получение информации об аккаунте и приложении |
| `create_payment()`           | Создание нового платежа                       |
| `payment()`                  | Альтернативный метод создания платежа         |
| `get_payment(payment_id)`    | Получение информации о конкретном платеже     |
| `cancel_payment(payment_id)` | Отмена платежа                                |
| `wait_for_payment()`         | Ожидание изменения статуса платежа            |

### `me()`

Получает информацию об аккаунте и подключённом приложении.

Используется для проверки подключения и получения доступных данных аккаунта.

### `create_payment()`

Создаёт новый платёжный счёт.

После создания платежа разработчик получает данные, необходимые для дальнейшей работы с оплатой.

### `payment()`

Альтернативный метод создания платежа.

### `get_payment(payment_id)`

Позволяет получить актуальную информацию о платеже по его идентификатору.

Используется для проверки состояния ранее созданного платежа.

### `cancel_payment(payment_id)`

Отправляет запрос на отмену платежа.

### `wait_for_payment()`

Позволяет ожидать изменения статуса платежа, чтобы не реализовывать собственный механизм постоянной проверки вручную.

## 6. Работа с платежами

Типичный процесс интеграции PayTrade API состоит из нескольких этапов:

1. Разработчик подключает SDK или самостоятельно настраивает HTTP-запросы.
2. Приложение обращается к PayTrade API.
3. Создаётся платёжный счёт.
4. Пользователь переходит по платёжной ссылке.
5. Оплата производится через официального Telegram-бота PayTrade.
6. Приложение получает возможность проверить состояние платежа.
7. После подтверждения оплаты приложение выполняет необходимые действия со своей стороны.

Платёжные ссылки ведут в официальный Telegram-бот PayTrade.

Указанный разработчиком Telegram-бот используется для возврата пользователя после завершения оплаты.

## 7. Тестовый режим

В PayTrade API предусмотрен тестовый режим.

Он предназначен для проверки интеграции и отображения платёжного процесса без реального списания Telegram Stars.

Тестовый режим позволяет разработчику проверить:

- Создание платежей.
- Формирование платёжных ссылок.
- Отображение платёжной информации.
- Получение статуса платежа.
- Обработку результата оплаты.

Тестовые операции отделены от реальных платежей.

## 8. Обработка ошибок

При работе с SDK можно использовать исключение `PayTradeError`.

Оно предназначено для обработки ошибок, возникающих при взаимодействии с PayTrade API.

Рекомендуется учитывать возможные ошибки при создании, получении и отмене платежей, чтобы приложение могло корректно реагировать на неудачные запросы.

## 9. FAQ

**Можно ли использовать PayTrade API без маркетплейса?**

Да. PayTrade API — самостоятельный продукт, который можно интегрировать в сторонние проекты.

**Можно ли подключить API к Telegram-боту?**

Да. API предназначен в том числе для интеграции в Telegram-боты.

**Какая валюта используется для платежей?**

Для платежей используется Telegram Stars.

**Можно ли проверить оплату без реального списания Stars?**

Да. Для этого предусмотрен тестовый режим.

**Куда ведут платёжные ссылки?**

На официальный Telegram-бот PayTrade.

**Связаны ли Marketplace и API?**

Это два самостоятельных продукта. Их объединяет общий баланс PayTrade.

**Можно ли получать средства от API на баланс PayTrade?**

Да. Полученные через API средства можно зачислять на баланс PayTrade.

**Можно ли пополнять баланс бота с помощью CryptoBot?**

Да. С помощью CryptoBot можно пополнять баланс PayTrade в звёздах.
