PayTrade Marketplace — маркетплейс цифрових товарів і послуг із гарантом з боку PayTrade.

Платформа призначена для купівлі та продажу цифрових товарів. Угоди проходять через PayTrade, який забезпечує послідовність передавання товару та підтвердження оплати.

1. Покупець обирає потрібний товар у каталозі.
2. Покупець оформлює замовлення та здійснює оплату.
3. Після підтвердження оплати створюється замовлення.
4. Продавець передає товар покупцеві.
5. Покупець перевіряє отриманий товар і підтверджує отримання.
6. Після підтвердження кошти зараховуються продавцеві на баланс PayTrade.

Таким чином, продавець отримує кошти після підтвердження отримання товару покупцем.

- Каталог цифрових товарів.
- Пошук товарів за назвою.
- Категорії товарів.
- Картки товарів з описом і ціною.
- Профілі продавців.
- Система оцінок і відгуків.
- Кошик та оформлення замовлень.
- Обрані товари.
- Керування власними оголошеннями.
- Зміна інформації про товари.
- Знижки та просування оголошень.
- Оплата через баланс PayTrade і Telegram Stars.
- Історія покупок.
- Звернення до служби підтримки.

PayTrade API — самостійний платіжний інтерфейс, призначений для розробників, які хочуть підключити PayTrade до власних проєктів.

За його допомогою можна створювати платежі, отримувати інформацію про них, скасовувати платежі та відстежувати зміну їхніх статусів.

API підходить для інтеграції в:

- Telegram-боти.
- Інтернет-магазини.
- Маркетплейси.
- Вебзастосунки.
- Сторонні сервіси.
- Інші проєкти, яким потрібна система приймання платежів.

PayTrade API не керує товарами, оголошеннями або угодами маркетплейсу. Він відповідає за платіжну частину сторонніх проєктів.

- Отримання інформації про обліковий запис.
- Створення платіжних рахунків.
- Отримання інформації про платежі.
- Скасування платежів.
- Відстеження статусів платежів.
- Очікування зміни статусу платежу.
- Тестовий режим.
- Приймання платежів у Telegram Stars.
- Зарахування отриманих через API коштів на баланс PayTrade.
- Виведення отриманих через API Telegram Stars на баланс PayTrade.

PayTrade Marketplace і PayTrade API є двома самостійними продуктами.

Їх об'єднує спільний баланс PayTrade.

Кошти, доступні на балансі, можуть використовуватися в межах передбачених можливостей екосистеми.

PayTrade SDK — Python-бібліотека для зручної роботи з PayTrade API.

SDK надає готові методи для взаємодії з API, тому розробнику не потрібно самостійно реалізовувати кожен HTTP-запит.

- Python 3.10 або новіший.
- Встановлений PayTrade SDK.
- API-ключ PayTrade.

SDK поширюється у форматі `.whl`.

Після отримання файлу бібліотеки встановіть її командою:

```bash
pip install paytrade_sdk-0.2.0-py3-none-any.whl
```

Після встановлення бібліотека доступна для імпорту:

```python
from paytrade_sdk import PayTrade, PayTradeError
```

Для роботи з API необхідно створити екземпляр `PayTrade`, передавши йому API-ключ і адресу API.

Базова адреса API:

```text
https://a-ktj8.onrender.com
```

API-ключ використовується для авторизації запитів.

SDK надає такі основні методи:

| Метод | Опис |
|---|---|
| `me()` | Отримання інформації про обліковий запис і застосунок |
| `create_payment()` | Створення нового платежу |
| `payment()` | Альтернативний метод створення платежу |
| `get_payment(payment_id)` | Отримання інформації про конкретний платіж |
| `cancel_payment(payment_id)` | Скасування платежу |
| `wait_for_payment()` | Очікування зміни статусу платежу |

Отримує інформацію про обліковий запис і підключений застосунок.

Використовується для перевірки підключення та отримання доступних даних облікового запису.

Створює новий платіжний рахунок.

Після створення платежу розробник отримує дані, необхідні для подальшої роботи з оплатою.

Альтернативний метод створення платежу.

Дозволяє отримати актуальну інформацію про платіж за його ідентифікатором.

Використовується для перевірки стану раніше створеного платежу.

Надсилає запит на скасування платежу.

Дозволяє очікувати зміну статусу платежу, щоб не реалізовувати власний механізм постійної перевірки вручну.

Типовий процес інтеграції PayTrade API складається з кількох етапів:

1. Розробник підключає SDK або самостійно налаштовує HTTP-запити.
2. Застосунок звертається до PayTrade API.
3. Створюється платіжний рахунок.
4. Користувач переходить за платіжним посиланням.
5. Оплата здійснюється через офіційного Telegram-бота PayTrade.
6. Застосунок отримує можливість перевірити стан платежу.
7. Після підтвердження оплати застосунок виконує необхідні дії зі свого боку.

Платіжні посилання ведуть до офіційного Telegram-бота PayTrade.

Зазначений розробником Telegram-бот використовується для повернення користувача після завершення оплати.

У PayTrade API передбачено тестовий режим.

Він призначений для перевірки інтеграції та відображення платіжного процесу без реального списання Telegram Stars.

Тестовий режим дозволяє розробнику перевірити:

- Створення платежів.
- Формування платіжних посилань.
- Відображення платіжної інформації.
- Отримання статусу платежу.
- Обробку результату оплати.

Тестові операції відокремлені від реальних платежів.

Під час роботи із SDK можна використовувати виняток `PayTradeError`.

Він призначений для обробки помилок, що виникають під час взаємодії з PayTrade API.

Рекомендується враховувати можливі помилки під час створення, отримання та скасування платежів, щоб застосунок міг коректно реагувати на невдалі запити.

**Чи можна використовувати PayTrade API без маркетплейсу?**

Так. PayTrade API — самостійний продукт, який можна інтегрувати у сторонні проєкти.

**Чи можна підключити API до Telegram-бота?**

Так. API призначений, зокрема, для інтеграції в Telegram-боти.

**Яка валюта використовується для платежів?**

Для платежів використовуються Telegram Stars.

**Чи можна перевірити оплату без реального списання Stars?**

Так. Для цього передбачено тестовий режим.

**Куди ведуть платіжні посилання?**

До офіційного Telegram-бота PayTrade.

**Чи пов'язані Marketplace та API?**

Це два самостійні продукти. Їх об'єднує спільний баланс PayTrade.

**Чи можна отримувати кошти від API на баланс PayTrade?**

Так. Отримані через API кошти можна зараховувати на баланс PayTrade.
